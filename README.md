# 🛒 Shopping Cart – E-Commerce Web Application

A full-stack *E-Commerce Shopping Cart application* built using *Node.js, Express.js, MongoDB, and Handlebars*.  
This project demonstrates a complete online shopping workflow including product management, cart system, order processing, and payment integration.

---

## 🌐 Live Demo
Live App: https://shopping-cart-2c4h.onrender.com  

GitHub: https://github.com/anaswararbabu/shopping-cart

---

## 🚀 Features

### 👤 User
- User Signup & Login
- View products
- Add to cart
- Update cart quantity
- Remove items from cart
- Place orders
- Payment options:
  - Cash on Delivery
  - Online Payment via Razorpay
- Order tracking
- Cancel orders
- View order history

### 🔑 Admin
- Admin login
- Add / Edit / Delete products
- Upload product images
- View all orders
- Update order status

Order Status Flow:
Placed → Shipped → Out for Delivery → Delivered → Cancelled
